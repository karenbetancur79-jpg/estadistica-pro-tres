# ESTADÍSTICA PRO

Aplicación académica para distribuciones muestrales con Streamlit.

## Archivos
- `app.py`: aplicación principal.
- `requirements.txt`: bibliotecas necesarias.

## Ejecutar localmente
1. Instala Python 3.10 o superior.
2. Abre una terminal en esta carpeta.
3. Instala dependencias:
   `pip install -r requirements.txt`
4. Ejecuta:
   `streamlit run app.py`
5. Abre la dirección local que muestra Streamlit.

## Publicar en internet gratis
1. Crea una cuenta en GitHub.
2. Crea un repositorio llamado `estadistica-pro`.
3. Sube `app.py` y `requirements.txt`.
4. Entra a https://share.streamlit.io/ e inicia sesión con GitHub.
5. Pulsa **Create app**.
6. Selecciona el repositorio, la rama `main` y el archivo `app.py`.
7. Pulsa **Deploy**. Se generará una dirección pública terminada en `streamlit.app`.

La aplicación es pública si no configuras restricciones de acceso. No subas datos personales o confidenciales.
